# Student Grade Calculator

## Description

Student Grade Calculator is a simple Python mini project that calculates a student's total marks, percentage, grade, and pass/fail result.

## Features

- Accepts student name
- Accepts marks for 5 subjects
- Calculates total marks
- Calculates percentage
- Assigns a grade
- Displays Pass or Fail

## Technologies Used

- Python

## Grading System

- 90% and above: A+
- 80% - 89%: A
- 70% - 79%: B
- 60% - 69%: C
- 50% - 59%: D
- Below 50%: E
- If any subject mark is below 35: Fail

## How to Run

1. Install Python.
2. Open the project in VS Code.
3. Open the terminal.
4. Run:

python student_grade_calculator.py
